# Port notes

CFlow started as a port of the [BFlow Financial Engine](https://github.com/DiazzzDev/BFlow-Financial-Engine)
(Spring Boot). These differences are intentional:

- **Single tenant.** Users, Cognito, shared wallets, invitations, member roles and contributor fields
  are gone, and so are plan limits and Wompi subscriptions.
- **One account.** Wallets, transfers, stored balances, overdraft checks and quick expenses are gone;
  expenses and incomes are one `transactions` table with signed amounts. Separate accounts could come
  back as a plugin that links transactions to its own tables.
- **No budgets or reports yet.** They were ported, then parked to come back as plugins. The dashboard
  covers the month's totals and spending by category.
- **Error codes.** The original answered 404 for a wrong category type. Now bad input is 400 and 404 is
  only for missing records.
- **Leaner schema.** Columns nothing read are gone: `confidenceScore`, `editCount`,
  `categorizationChanges`, `autoGenerated` and category `systemDefined`. Categories must be `INCOME` or
  `EXPENSE`.
- **USD only, for now.** Transactions keep a `currency` column, which defaults to `USD` and is optional
  in requests, but `USD` is the only accepted value. Multi-currency support would start by extending
  `CURRENCIES` in `api/src/plugins/ledger/transactions.ts`.
- **No idempotency keys.** CFlow only tracks money, so a retried request at worst records a duplicate
  you can delete. The `Idempotency-Key` header and its table are gone.
- **A slimmer envelope.** Successful responses are `{ success, data }`, without the original
  `message`, `timestamp` and `path`; errors keep them. Deletes return 204 with no body.
- **English only.** Messages and chart labels are in English; there is no localisation until it is
  needed.

## Not yet ported

Receipts and OCR (S3, Textract, SQS, SNS), file storage, CSV transaction import and merchant detection,
email templates, push notifications, legal documents, the audit log, contact forms and account
deletion.
